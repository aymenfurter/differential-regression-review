# Code of conduct

We want technical discussion in this project to be direct, useful, and respectful.

Contributors must:

- focus feedback on the work, evidence, and user effect;
- state uncertainty and avoid unsupported claims;
- protect private code, credentials, and personal information;
- accept correction without personal attacks;
- avoid harassment, discrimination, threats, or unwanted contact.

Report conduct concerns privately to the repository owner. The owner can edit or remove
content and can limit participation when needed to keep the project safe and useful.
