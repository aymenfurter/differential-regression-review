## [1.0.0] - 2026-08-29

### Added

- Risk-ranked disposable end-to-end probes across base and PR revisions.
- Independent maximum-reasoning risk analysis across strong model providers.
- Up to 100 browser, API, CLI, and service-contract probes.
- Base control checks, repeat PR runs, and Critical/High sensitivity proof.
- Rounded residual risk with named LOW, MODERATE, ELEVATED, and SEVERE levels.
- GitHub Copilot app KaTeX risk tables and three-card result summary.
- Gated `LGTM` or `NEEDS WORK` review verdict.
- Evidence-backed draft comments or local recommended actions.
- Safe worktree isolation, cleanup, credential, and production rules.
- GitHub CLI validation workflow and contributor templates.
